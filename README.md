
# Retail Sales Performance - Exploratory Data Analysis

## 📊 Project Overview
This project focuses on exploring and analyzing retail transaction data to uncover key purchasing patterns, customer behaviors, and sales trends. Using Python, the raw transaction logs were cleaned and transformed into actionable business insights.

## 🎯 Key Objectives
* **Data Cleaning:** Handled missing values, formatted timestamps, and isolated invalid or negative transaction values (like returns).
* **Trend Analysis:** Identified peak sales periods across hours, days of the week, and months.
* **Customer Behavior:** Analyzed top-performing product categories and average order values (AOV).

## 🛠️ Technologies Used
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook
